OneBot 11 连接

适配 NapCat、LLOneBot、Lagrange.OneBot 等 OneBot 11 实现。配置仅保存在本机 Agent。

正在读取状态…

正向 WebSocket 和 HTTP API 必填；反向模式由 Agent 监听，无需填写。

反向 WebSocket / HTTP POST 使用。非回环监听必须配合 Access Token 和防火墙；启用工作区工具或管理员时，回环监听也必须设置 Token。

留空保留已保存的 Token。

群聊 @ 检测需要机器人 QQ；通常可留 0，由事件 self_id 自动识别。

图片读取与安全

支持 PNG、JPEG、GIF、WebP；每条消息最多 4 张。下载会校验实际连接 IP，默认阻止回环、私有和链路本地地址。

合并转发

默认只保留合并转发占位。OneBot 11 无法验证转发 ID 属于当前会话；仅在协议端可信且需要读取转发内容时开启。

好友申请与群邀请

默认忽略所有申请。开启后也不会接受陌生 QQ 或未配置群；加群后的聊天权限仍按下方群配置执行。

私聊权限

未列出的 QQ 私聊会被忽略。管理员模式可完整操作 Agent 主机，仅授予可信账号。

群聊权限

未列出的群会被忽略。共享会话由全群共用；成员会话按 QQ 隔离。

聊天命令：/help、/new、/stop、/status、/id

测试消息

保存并连接后，向指定私聊或群发送一条消息，不启动 Codex 任务。
